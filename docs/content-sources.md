## 미확정 자료

- 대표 공식 인물 사진, 상세 프로필과 경력
- 교육·세미나 현장 사진 및 이미지별 설명
- 최신 커리큘럼, 과정별 Level, 평가·발급 절차
- 협회 연혁, 비전의 공식 문안, 전체 파트너 목록과 공개 범위
- 날짜·본문이 검증된 뉴스/공지 게시물
- 정식 개인정보 처리방침과 이용약관

소식 영역은 가짜 최신 게시글 대신 공식 블로그·기존 자격과정·MOU 기록을 연결한다.

## 언어와 배포

KR/EN/CN/JP 콘텐츠를 독립 TypeScript 파일로 관리. 원본 외부 링크의 도착 페이지는 기존 사이트 언어를 따른다. 현재 페이지는 로컬 검수용 noindex 상태이며 배포하지 않았다.
